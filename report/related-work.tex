\section{Related Work}

\subsection{High-Performance Computation}

\paragraph{Multi-Processor Programming Frameworks} POSIX-Thread\citep{pthread}
(or Pthreads) and OpenMP\citep{openmp} are two commonly-used shared-memory 
multi-processor parallel programming frameworks.  A single process can have 
several POSIX threads, executing certain parts of the program in 
parallel. The programmers have to explicitly spawn or destroy POSIX threads.
OpenMP, on the other hand, implicitly manages threads, therefore
offering programmers a simple \texttt{\#pragma omp} directive to parallel execution of 
loops\footnote{An example of this is in Figure~\ref{code:ompdemo}}.
Our thread pool implementation discussed in Section~\ref{sec:impl:tp}
is based on POSIX-Thread because it offers explicit way to 
synchronize the worker and host threads.

\paragraph{Compiler Support for HPC} Compiler optimizations  has become an
integral part of modern high-performance computer systems. As these 
optimizations become increasingly effective and versatile, programmers
can be less concerned about the underlying intricate details of hardware
architectures. Most optimizations for uni-processors reduce the number of
instructions executed by the program using program analysis based 
transformations\citep{compiler-for-hpc}. However, since there exist several
different parallel computing architectures(vector-CPU, shared-memory
multi-processor, distributed-memory multi-processor), automatically 
parallelize code remains highly challenging for compilers.

\paragraph{Optimizing C++ Softwares}

\par Dean et al. has proposed many optimization techniques 
to improve the performance of softwares written in \texttt{C++}
\citep{perfhint}. Some key insights include better measurements
to better understand program bottle-neck, allocate objects
on stack to reduce heap memory allocation (potentially slow), 
avoid unnecessary function calls (by storing return value in temporary
objects), and use lock-free operations. It is worth noting that 
more optimizations are possible, such as applying faster memory
allocators (e.g. Google's \texttt{tcmalloc}\citep{tcmalloc}),
memory alignment to avoid cache misses, etc. Among all the optimization
techniques we applied, our code benefited most from
multi-threading parallelism via our crafted thread pool.

\subsection{Community Detection Algorithms}

\par We investigate two types of community detection algorithms,
Community Structure\citep{girvan2002community}  and AGM\citep{yang2012structure}.

\paragraph{Community Structured Based Method} A conspicuous property of 
community structure is that network nodes are tightly joined, and that
there are only loose connections between communities. Based on this,
Girvan et al. proposed a method to detect such community structure and
find non-overlapping communities in both social and biological networks
\citep{girvan2002community}. It iteratively computes the "betweenness"\citep{freeman1977graph}
of each edge, removes the edge with highest "betweenness", and terminates
when there is no edges left. This method captures community structure
with high accuracy and sensitivity. However, betweenness calculation algorithm's 
complexity  is $O(|E| |V|)$ for network $G(V,E)$, resulting in an
entire worst-case time of $O(|E|^2 |V|)$.

\paragraph{AGM} \textit{Community-Affiliation Graph Model}\citep{yang2012structure}
is a conceptual model of network community structure, which detects 
\textbf{overlapping} network communities. Given a network graph $G(V,E)$, the
goal is to create a bipartite affiliation graph $B(V, C, M)$, where
$u\in V$ is a node(vertex), $c\in C$ is a community, 
$k\in M$ is an edge $(u,c)$ if $u$ belongs to community $c$. Each
community $c\in C$ has a probability $p_c\in [0,1]$.
For each edges $(u,v)\in G(E), u,v \in V$, the likelihood of it is 
\begin{align}
    p_(u,v) &= 1- \prod_{k\in C_{uv}}(1-p_k)
\end{align},
where $C_{uv}\subset C$ is a set of communities $u,v$ have in common.
The community detection problem is now to optimize the likelihood of 
observed edges $G(E)$: 
\begin{align} \label{form:agmopt}
    \text{argmax}_{\{p_c\}} L(\{p_c\}) &= \prod_{(u,v)\in E} p(u,v) 
        \prod_{(u,v)\notin E} (1 - p(u,v))\\
    &\equiv \sum_{(u,v)\in E}\log{(1 - \prod_{k\in C_{uv}} (1-p_k))} + 
        \sum_{(u,v)\notin E}\sum_{k\in C_{uv}} \log{(1-p_k)}
\end{align}
Problem~\ref{form:agmopt}\footnote{It can be seen that $\{p_c\}$ is the parameters to fit.}
can be converted to a convex optimization 
problem and solved efficiently\citep{yang2012structure}. 
With this model, Yang et al.\citep{yang2012structure} concluded that overlaps of communities are
usually densely connected, and that ground-truth communities contain
high-degree hub nodes that reside in community overlaps.

\subsection{Node Centrality Algorithms}

\paragraph{Degree Centrality}
Degree centrality\citep{centralityclarify, centralitymeasures} 
is the most direct measure of node importance and is defined as the number of edges incident to a node. 
For a node $v$ in a graph $G(V,E)$, the degree centrality $C_D(v)$ is simply:
\begin{align} \label{form:degree}
    C_D(v) = \deg(v)
\end{align}
where $\deg(v)$ denotes the degree of node $v$, i.e., the number of edges connected to $v$.
For directed graphs, we can distinguish between \emph{in-degree} $C_D^{in}(v)$ (number of incoming edges) 
and \emph{out-degree} $C_D^{out}(v)$ (number of outgoing edges).
It reflects the level of \emph{local connectivity} of a node within the network.
Nodes with high degree centrality can directly reach a large number of neighbors, granting them strong immediate influence. 
While degree centrality does not account for the importance of neighboring nodes or the global network structure, 
it serves as an intuitive and effective baseline for identifying highly connected or active nodes.


\paragraph{Betweenness Centrality}
Betweenness centrality\citep{betweennesscentrality, fastercentrality}
measures the extent to which a node lies on shortest paths between other pairs of nodes. 
It quantifies how frequently a node acts as an intermediary in the flow of information across the network.
For a node $v$ in a graph $G(V,E)$, the betweenness centrality $C_B(v)$ is defined as:
\begin{align} \label{form:betweenness}
    C_B(v) = \sum_{s \neq v \neq t \in V} \frac{\sigma_{st}(v)}{\sigma_{st}}
\end{align}
where $\sigma_{st}$ is the total number of shortest paths from node $s$ to node $t$, 
and $\sigma_{st}(v)$ is the number of those shortest paths that pass through node $v$.
Nodes with high betweenness centrality play a critical \emph{bridging role}, 
connecting otherwise weakly connected regions or communities of the network. 
Such nodes may not exhibit high degree or global influence, yet they are structurally indispensable for facilitating communication and information diffusion.
In our analysis, betweenness centrality is used to highlight broker nodes that control or mediate interactions between different parts of the network. 
The comparison between betweenness-based rankings and other centrality measures reveals distinct notions of importance captured by different metrics.

\paragraph{PageRank}
PageRank\citep{websearchengine, googlepagerank}
is a global centrality measure based on a random walk model over the network. 
It estimates the long-term probability that a random walker visits a given node, 
assuming that the walker follows outgoing edges with a fixed probability $d$ (damping factor) and randomly jumps to any node with probability $(1-d)$ (teleportation probability). 
The PageRank score $PR(v)$ for node $v$ is computed iteratively as:
\begin{align} \label{form:pagerank}
    PR(v) = \frac{1-d}{N} + d \sum_{u \in M(v)} \frac{PR(u)}{L(u)}
\end{align}
where $N$ is the total number of nodes in the network, $M(v)$ is the set of nodes that link to $v$, 
$L(u)$ is the number of outgoing edges from node $u$, and $d \in [0,1]$ is the damping factor (typically set to $0.85$).
As a result, PageRank assigns higher scores to nodes that are linked by other highly ranked nodes.
In the context of network analysis, 
PageRank reflects a node's \emph{global influence} and authority. 
Nodes with high PageRank are not necessarily those with the largest number of direct connections, 
but those endorsed by other important nodes. 
This property makes PageRank particularly suitable for directed networks such as citation networks, 
where link direction carries semantic meaning and indicates the flow of influence.
In this report, PageRank is used to identify globally influential nodes and to characterize the overall centralization of influence within the network. 
The resulting PageRank scores are further analyzed through distribution plots and Top-K rankings.
